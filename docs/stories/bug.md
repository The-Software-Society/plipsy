# bug — Hug the Bug

Unit 15 · Module 1. Implemented in `src/stories/bug.ts`.
[← Curriculum](../CURRICULUM.md) · [Story specs](README.md)

## At a glance
- **Hero word:** BUG
- **Target words:** HUG · SUN · BUG
- **Review words:** RUN
- **Phonics focus:** short U · `-ug` / `-un` families
- **Moral:** kindness to the smallest — the tiniest friend gets the gentlest care.
- **Characters:** Mia, **Bea** (ladybug, debut)

## Structure
One branch (sun vs hug), reconverging into BUG (hero) and a RUN review.

```
s1 → s2 ─choice─┬ SUN → s3a ─┐
                └ HUG → s3b ─┴→ s4 (spell BUG, hero) → s5 (spell RUN, review) → s6 (end)
```

## Scene-by-scene

### s1 — a cold little bug
- *"Mia finds a tiny BUG on a cold leaf."* — tone: gentle — highlights: **BUG**
- *"Poor Bea is too chilly to fly."* — tone: soft
- → continue to s2

### s2 — how to warm her
- **Choice — "How can we warm up the little bug?"**
  - **SUN** → s3a
  - **HUG** → s3b

### s3a — into the sun
- *"Mia lifts the leaf into a patch of warm sun."* — tone: kind
- **Spell SUN** — prompt *"Spell SUN!"* → s4

### s3b — cupped hands
- *"Mia cups her hands into a soft little hug."* — tone: tender
- **Spell HUG** — prompt *"Spell HUG!"* → s4

### s4 — wings open (hero)
- *"The little BUG opens her shiny wings!"* — tone: cheer — highlights: **BUG**
- **Spell BUG** ⭐ hero — prompt *"Spell BUG!"* → s5

### s5 — off through the grass (review)
- *"Mia and Bea RUN through the tall grass."* — tone: playful — highlights: **RUN**
- **Spell RUN** (review) — prompt *"Spell RUN!"* → s6

### s6 — end
- *"Bea is the smallest friend of all."* — tone: warm
- *"Be kind to the tiniest one!"* — tone: warm
- → end
